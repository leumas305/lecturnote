Introduction

lecturnote is a keyboard-first, offline note-taking app built for computational biology, bioinformatics, and mathematics. It's designed for the moment when you're taking rapid lecture notes and need to insert a matrix, a fraction, a sequence alignment, or a concept map without breaking your typing flow.

Every action has a keyboard shortcut. Math renders live as you type using KaTeX. Notes are stored locally, never sent anywhere.

Try it live

Every "Try it live" block on this page is fully editable — type in the left pane and see the rendered output on the right. It's the same syntax the real app uses.

Getting started

On first launch you'll see an empty note. Start typing markdown — it renders in the right pane in real time. To insert a math expression, wrap it in $( )$ for inline or $$( )$$ for display mode. Alternatively press $ and lecturnote will insert the delimiters for you with your cursor placed inside, ready to type.

Keyboard shortcuts

Everything in the app has a shortcut. All are remappable via the settings panel (Ctrl+,). You can change both the key and the modifier family (Ctrl / Ctrl+Alt / Ctrl+Shift) per action.

Text formatting

lecturnote uses standard markdown for basic formatting. Bold is **bold**, italic is *italic*. Bold+italic combined shows in a distinct color so you can quickly tell it apart from either alone.

Colored boxes

Semantic boxes are what makes math notes actually scannable. Wrap content in :::type ... ::: and it renders as a colored block. Boxes support math, anchors, and everything else inside them.

Table of contents

Write %index% anywhere in your note and press Space or Enter. lecturnote inserts a clickable table of contents built from all your ##, ###, and #### headings. Headings are also auto-numbered in the preview (1., 1.1, 1.1.1) while your raw markdown stays clean.

Math basics

Math delimiters use parentheses inside dollar signs — this makes the math clearly bounded and easier to type than raw LaTeX:

  • $( )$ — inline math, flows with text
  • $$( )$$ — display math, centered on its own line

Press $ anywhere in the editor to insert the delimiters with your cursor placed inside. Press $ again while inside an empty math block to upgrade to display mode.

Fractions and operators

Fractions use (numerator)/(denominator). Big operators like sums and integrals take their bounds in parentheses.

Symbols and Greek letters

Type the name of any Greek letter to get it. Capitalize for uppercase Greek. Common operators and set symbols also have short names.

Matrices

Use mat(RxC) for an empty matrix or mat(RxC)[values] for a filled one. Values fill left-to-right, top-to-bottom.

Cases (piecewise functions)

Type cases and press Tab — a visual editor opens with two columns per row (expression + condition). Use Tab to move between cells, Enter to add a new row below, Ctrl+Enter to insert, and Esc to cancel.

Chemistry

Use chem(formula) to auto-format element subscripts and charges. Digits after letters become subscripts. Trailing +/- becomes the charge.

Chemistry snippets — type these and press Tab: water, hydronium, hydroxide, ammonia, ammonium, sulfate, phosphate, nitrate, carbonate, bicarb, glucose, atp.

Physics constants: NA or avogadro, planck, boltz, echarge, lightspeed.

Sequence blocks

Wrap biological sequences in a :::sequence block. The first line sets the type (DNA, RNA, or AA). Bases get color-coded automatically.

DNA: A=green, T=red, G=amber, C=blue. RNA: same but U replaces T. Amino acids: colored by chemistry class (hydrophobic, polar, charged).

FASTA headers (>seq_id) render in muted grey.

Graphs and concept maps

Draw layered graphs using a simple text syntax. Direction can be LR (default), TD, RL, or BT. Node styling: wrap the label in **text** for bold amber, or *text* for italic teal.

Example syntax:

:::graph LR
a: Node A
b: **Important**
c: *Optional*

a -> b : label
a --> c
b -- c
:::

Edge types:

SyntaxStyle
a -> bDirected arrow
a --> bBold directed arrow
a -- bUndirected line
a -.-> bDashed arrow
a -> b : labelAny type with label

Layout is computed automatically using the Sugiyama algorithm (dagre). Type graph + Tab for a starter template.

Exercises

Wrap problems in an :::exercise Name block with a :::solution section inside:

:::exercise Prove the Pythagorean theorem
State the problem clearly here.
:::solution
Full solution goes here.
:::

lecturnote inserts a reference chip at the position and collects all exercises at the bottom of the preview. Solutions are hidden by default with a toggle; when exporting to PDF all solutions are always visible.

Autocorrect

Real Hunspell spellchecking. Fires on Space or Enter after a mistyped word. A green flash means a correction was applied.

Two layers:

  1. Explicit dictionary — the AUTOCORRECT map in the source. Exact match, always wins over probabilistic suggestions. Use for domain-specific typos.
  2. Hunspell — real spell-checking with English (~49,000 words) and Spanish (~57,000 words) dictionaries including full morphology.

Toggle the language via the dropdown in the top bar (EN / ES / Both / Off). Default is Off.

Add your own words: select a word (or place cursor on it) and press Ctrl+Shift+D. Choose which dictionary to add it to. Additions persist across restarts.

PDF export

Press Ctrl+Shift+S to open the print dialog — save as PDF from there. Only the preview is printed. All exercise solutions are made visible. Page breaks avoid splitting boxes, code blocks, and tables. Page size is A4 with 2cm/2.5cm margins.

Customisation

Open index.html in any text editor. The top of the <script> section has a clearly-marked commands block you can edit:

  • MATH_FUNCTIONS — add new structured math commands
  • MATH_SYMBOLS — add new symbol shorthands
  • SNIPPETS — add subject-specific text expansions
  • AUTOCORRECT — add explicit typo corrections

Restart the app after editing.
